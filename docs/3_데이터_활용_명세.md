## 1. 필수 데이터 (제주데이터허브)

| 항목 | 내용 |
|---|---|
| 데이터명 | 「제주특별자치도_악취배출시설현황」 |
| 제공 | 제주특별자치도 · 제주데이터허브(jejudatahub.net/data/view/data/480), 공공데이터포털(data.go.kr/data/15056020) |
| 기준일 | 2019-07-19 |
| 규모 | 사업장 58곳 |
| 사용 항목 | 구분(악취관리지역 / 악취관리지역 외), 사업장명, 소재지(대표주소, 지번), 부지면적(㎡), 데이터기준일자 |
| 이용조건 | 「공공데이터의 제공 및 이용 활성화에 관한 법률」에 따른 공공데이터. 화면 하단과 이 명세에 출처 표기 |
| 원본 파일 | `data/raw/제주특별자치도_악취배출시설현황.csv` (원본 표를 그대로 옮김, UTF-8) |
| 전처리 결과 | `data/processed/facilities.csv` |
| 전처리 코드 | `scripts/prepare_facilities.py` |

### 전처리
1. **주소 → 읍면·리·지번 분리**: `제주특별자치도 제주시 애월읍 고성리 164` → 읍면 `애월읍`, 리 `고성리`
2. **좌표 변환**: 지번 주소를 국토교통부 **브이월드 지오코더 API**(`api.vworld.kr/req/address`, 지번 검색)로 위도·경도로 바꿉니다. 58곳 모두 변환 성공(`precision=지번`). 결과는 `data/processed/geocode_cache.json` 에 저장해 다시 묻지 않습니다. 브이월드 키가 없을 때는 OpenStreetMap Nominatim으로 리 중심 근사 좌표를 씁니다.
3. **중복 의심 표시** (6곳): 같은 주소에 사업장 2곳(세원농장·우진축산, 한림읍 금능리 16), 같은 이름이 주소 2곳(피그랜드 대지지점, 은성농장). 지우지 않고 `중복의심` 열에 표시합니다.
4. 사업장명은 파일에 남기되, 화면·Agent 답변에는 표시하지 않습니다(설정 `FACILITY_SHOW_NAMES=false`).

### 활용
| 어디에 | 어떻게 |
|---|---|
| 센터 화면 지도 | 58곳을 지번 좌표로 표시. 같은 좌표는 하나로 묶고 시설 수 표시. 누르면 구분·부지면적·중복 의심 |
| 말로 묻는 분석 (`facility_stats` 도구) | 읍면·리·구분별 시설 수, 악취관리지역 안 시설 수, 부지면적 합계를 계산해 Claude가 답함 |
| 목록 대조 | 광령리 실측 농장 4곳이 목록에 없음을 확인 → 지도·답변에 "목록 갱신 필요" 표시 |

| 정보공개청구 자료 | 제주시 (민원 1,778건·지도점검·행정처분, 2023.1~2026.9) | **제출물에 넣지 않음** | 청구인 수령 자료 | 기획서의 문제 정의 통계에만 사용 |
| 풍향 | 기상청 API (연결 예정) | 현재 기본값(남풍 4m/s, `.env` 로 변경) | — | 주의 알림 보낼 바람 위쪽 농장 고르기(내부) |

### 가상 신고 기록의 만들기 규칙 (`sim_history.py`)
- 날마다 냄새 정도를 없음 56% · 약함 22% · 보통 14% · 심함 8%로 정하고, 45% 확률로 전날과 같게 해 며칠씩 이어지게 합니다.
- "신고 없는 날 56%"는 정보공개청구 자료(민원 있는 날 596일 / 전체 1,369일 ≈ 44%)에 맞춘 값입니다.
- 시간대 분포는 실측 경향(오전 > 오후 > 저녁, 새벽 드묾)을 따르지만 숫자 자체는 가상입니다. 화면과 Agent 답변에 "가상 기록"임을 표시합니다.

## 3. 분석 흐름

```
주민 카톡 문장
  └─ parse_report (Claude 구조화 출력 → 실패 시 규칙)  → 마을·시각·강도·냄새 종류
       └─ engine: 같은 마을 1시간 묶기, 같은 사람은 1명으로 → 관찰·주의·경보·지속
            ├─ 주의: 바람 위쪽 농장에 주의 알림 (rank_sources, 내부용)
            ├─ 경보: 시청 대표 민원 전화 1통 + 문자 (같은 사건 3시간 동안 1번)
            └─ 지속: 민원서 초안 (구역 실측 통계 첨부) → 마을 대표 승인
  └─ report_stats: 기간·마을·시간대별 집계, 사건별 처리 경과

방문자 질문 (말로 묻는 분석)
  └─ Claude: 질문 해석 → 도구 선택 (report_stats / hourly_daily / incident_list / measurement_stats / facility_stats)
       └─ 도구(파이썬)가 계산 → Claude가 기간·출처와 함께 설명, 화면에 "Agent가 한 일" 공개
```

### Claude에 보내는 것과 보내지 않는 것
| 보냄 | 보내지 않음 |
|---|---|
| 주민 신고 문장 1개(해석용), 방문자 질문, 도구가 계산한 집계값 | 신고자 ID·연락처, 원본 행 목록, 사업장명, API 키 |

## 4. 외부 API·서비스

| 서비스 | 주소 | 용도 | 키 |
|---|---|---|---|
| Claude API (Anthropic) | api.anthropic.com | 말로 묻는 분석(`claude-sonnet-5-5`), 신고 해석(`claude-haiku-5-5`) | `ANTHROPIC_API_KEY` |
| 브이월드 | api.vworld.kr | 지오코더(전처리), 장소검색(전처리), 배경지도 타일(실행 중) | `VWORLD_API_KEY` (제출물에 넣지 않음, 발급 방법은 설치 매뉴얼) |
| OpenStreetMap | tile.openstreetmap.org, overpass-api.de, nominatim.openstreetmap.org | 배경지도(키 없을 때), 경계 받기(전처리), 근사 좌표(전처리) | 없음 |
