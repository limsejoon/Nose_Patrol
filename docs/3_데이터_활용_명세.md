## 1. 필수 데이터 (제주데이터허브)

| 항목 | 내용 |
|---|---|
| 데이터명 | 「제주특별자치도_악취배출시설현황」 |
| 제공 | 제주특별자치도 · 제주데이터허브(jejudatahub.net/data/view/data/480), 공공데이터포털(data.go.kr/data/15056020) |
| 기준일 | 2019-07-19 |
| 규모 | 2019년 파일 58행(현재 제주 전체의 고유 사업장 수와 다름) |
| 사용 항목 | 구분(악취관리지역 / 악취관리지역 외), 사업장명, 소재지(대표주소, 지번), 부지면적(㎡), 데이터기준일자 |
| 이용조건 | 「공공데이터의 제공 및 이용 활성화에 관한 법률」에 따른 공공데이터. 화면 하단과 이 명세에 출처 표기 |
| 원본 파일 | `data/raw/제주특별자치도_악취배출시설현황.csv` (원본 표를 그대로 옮김, UTF-8) |
| 전처리 결과 | `data/processed/facilities.csv` |
| 전처리 코드 | `scripts/prepare_facilities.py` |

### 전처리
1. **주소 → 읍면·리·지번 분리**: `제주특별자치도 제주시 애월읍 고성리 164` → 읍면 `애월읍`, 리 `고성리`
2. **좌표 변환**: 지번 주소를 국토교통부 **브이월드 지오코더 API**(`api.vworld.kr/req/address`, 지번 검색)로 위도·경도로 바꿉니다. 58곳 모두 변환 성공(`precision=지번`). 결과는 `data/processed/geocode_cache.json` 에 저장해 다시 묻지 않습니다. 브이월드 키가 없을 때는 OpenStreetMap Nominatim으로 리 중심 근사 좌표를 씁니다.
3. **중복 의심 표시** (6곳): 같은 주소에 사업장 2곳(세원농장·우진축산, 한림읍 금능리 16), 같은 이름이 주소 2곳(피그랜드 대지지점, 은성농장). 지우지 않고 `중복의심` 열에 표시합니다.
4. 사업장명은 파일에 남기되, 화면·Agent 답변에는 표시하지 않습니다(설정 `FACILITY_SHOW_NAMES=false`).

### 활용
| 어디에 | 어떻게 |
|---|---|
| 센터 화면 지도 | 58곳을 지번 좌표로 표시. 같은 좌표는 하나로 묶고 시설 수 표시. 누르면 구분·부지면적·중복 의심 |
| 말로 묻는 분석 (`facility_stats` 도구) | 읍면·리·구분별 시설 수, 악취관리지역 안 시설 수, 부지면적 합계를 계산해 Claude가 답함 |
| 목록 대조 | 광령리 실측 농장 4곳이 2019년 목록에 없음 → 답변에 목록 시점·범위를 함께 밝힘 (58행은 이 파일의 행 수, 지금 제주 전체 시설 수로 보지 않음) |

### 가상 신고 기록의 만들기 규칙 (`sim_history.py`)
- 날마다 냄새 정도를 없음 56% · 약함 22% · 보통 14% · 심함 8%로 정하고, 45% 확률로 전날과 같게 해 며칠씩 이어지게 합니다.
- 실제 민원 자료에서 민원 있는 날은 1,369일 중 652일(약 48%)입니다. 가상 기록은 이와 비슷하게 "신고 없는 날"을 절반 남짓(56%)으로 정했습니다.
- 시간대 분포는 실측 경향(오전 > 오후 > 저녁, 새벽 드묾)을 따르지만 숫자 자체는 가상입니다. 화면과 Agent 답변에 "가상 기록"임을 표시합니다.

## 3. 분석 흐름

```
주민 카톡 문장
  └─ parse_report (Claude 구조화 출력 → 실패 시 규칙)  → 마을·시각·강도·냄새 종류
       └─ engine: 같은 마을 최근 60분 판단창(기본 설정에서 6시간 무신고 시 새 사건), 같은 사람은 1명으로 → 관찰·주의·경보·지속
            ├─ 주의: 바람 위쪽 농장에 주의 알림 (rank_sources, 내부용)
            ├─ 경보: 시청 대표 민원 전화 1통 + 문자 문안 (같은 사건 3시간 동안 1번, 대회판은 실제 발신 안 함)
            └─ 지속: 민원서 초안 (구역 실측 통계 첨부) → 마을 대표 승인
  └─ report_stats: 기간·마을·시간대별 집계, 사건별 처리 경과

방문자 질문 (말로 묻는 분석)
  └─ Claude: 질문 해석 → 도구 선택
       실제: complaint_history / coverage_compare / inspection_history / measurement_stats
       지정: facility_stats    시연: report_stats / hourly_daily / incident_list
       └─ 도구(파이썬)가 계산 → Claude가 기간·출처와 함께 설명, 화면에 "Agent가 한 일" 공개
```

### Claude에 보내는 것과 보내지 않는 것
| 보냄 | 보내지 않음 |
|---|---|
| 주민 신고 문장 1개(해석용), 방문자 질문, 도구가 계산한 집계값 | 별도 신고자 ID·연락처 필드, 행정 원문 행 목록, 사업장명, API 키 |

## 3-1. 정보공개청구 PDF → CSV 정규화 규칙 (`scripts/prepare_admin_records.py`)

| 규칙 | 내용 | 결과 |
|---|---|---|
| 민원 1건 | 접수시각 1개 = 1건. 한 칸에 시각이 여러 개면 각각 셈 | 원본 표 행 → 1,779개 기록 |
| 시각 표기 | `1700` → 17:00, `21;36` → 21:36 | 유효 시각 1,761개 |
| 시각 미상 | `-` 17개는 건수에 넣고 시간대 분석에서 뺌 | |
| 있을 수 없는 시각 | 2025-08-18 `24:14` 1개는 원문(`time_raw`)만 남기고 건수·시간대 모두에서 뺌 (다음 날 00:14로 고치지 않음) | **민원 1,778건** |
| 날짜 두 개인 행 | `9/3 9/4 19:34 7:09`, `2026-06-03 2026-06-04 23:16 00:04` → 시각과 순서대로 짝. 연도 없으면 앞 행 연도 | 12개 기록 연도 보완 |
| 접수방법 | 당직민원·전화·인터넷(국민신문고)·도청 전달·진정 | |
| 처리 종류 | 처리내용에 '방제', '저감·농장주·농가', '문자', '현장·점검', '답변·통화'가 있는지 (한 건에 여러 개 가능) | 원문은 옮기지 않음 |
| 지도점검 분류 | '포집·분석 의뢰'(포집 후 분석 의뢰·포집 실시), '포집 시도', '포집 예정·안내', '분뇨 시료채취', '시설 철거·폐쇄 확인', '민원 현장확인', '합동 지도점검', '기타' — '포집조'(시설 이름)는 포집으로 세지 않음 | 673행·210일, 포집·분석 의뢰 25행·13일 |
| 정기 실측 시간표 | 지금: 08~11·14~17·18~20시. 2024년까지는 20~22시도 있었음. 구간은 시작 포함·끝 미포함 | 시간표 밖 67.8%(지금 시간표) / 54.3%(해마다 그 해 시간표) |

검산: 위 숫자는 `scripts/check.py` 가 매번 다시 계산해 확인합니다. 기획서 초안의 "민원 있는 날 596일"은 재현되지 않아 이 규칙의 652일로 고쳤습니다.

**알 수 없는 것**: 접수 시각은 냄새가 난 시각이 아님 · 민원인 정보가 없어 사람 수·반복 여부를 모름 · 점검·처분·액비살포는 광령리·고성리 합계라 광령리 민원과 나눠 대응률을 내면 안 됨 · 시험성적서가 없어 포집 결과를 모름 · 행정처분 4사례 중 요청 기간(2023~) 안은 1사례.

### 실측 기준
광령리 A구역은 2018년 지정 **악취관리지역**이라 부지경계 복합악취 배출허용기준이 **희석배수 10**입니다(일반지역 15). 근거: 제주특별자치도 악취 배출허용기준 조례 별표, 제주도 발표 "복합악취 10배수 기준(악취관리지역), 15배수 기준(일반지역)"(2021.10). 초안에서 쓰던 15 초과는 참고 지표로만 남겼습니다. 정기 실측의 기준 초과는 행정처분과 같은 것이 아닙니다.

### 자유문장 전송의 한계

신고 해석에는 주민이 입력한 신고 문장 자체를 LLM에 보냅니다. 별도 ID·연락처 필드를 보내지 않는 것과 자유문장 속 개인정보가 자동 제거되는 것은 다릅니다. 현재 자동 마스킹은 구현하지 않았으며 현장 운영 전 보완합니다.
