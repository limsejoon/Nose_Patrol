## 화면과 실행 근거의 구분

- 주민 화면은 설명용 대화 예시다. 실제 카카오 채널 연동으로 표시하지 않는다.
- 농장주 이미지는 2026-11-10 실행 캡처, 센터 이미지(9쪽)는 2026-11-13 현재 버전 실행 캡처(가상 신고, 아침 시연 12건 후 광령2리 경보)다. 데이터는 모두 가상이다.
- 12쪽 첫 질문은 2026-11-11 실제 `/api/ask` 호출의 응답과 도구 기록을 문서용으로 요약했다. 둘째 질문(행정처분)은 2026-11-11 질문 15개 평가(`docs/6_질문_평가_결과.md`)의 답을 요약했다. 원문 전체는 `docs/evidence/analysis_run_2026-11-11.json`이다.
- 실제 호출은 `coverage_compare` 두 번, 현재/당시 시간표 각각 비교이며 관측 응답 시간은 8.3초다. 평균 성능이 아니다.
- 대회판은 실제 전화·문자·공식 민원 전송을 하지 않는다. 농장주 화면 알림과 응답, 문안 생성, 승인 기록을 시연한다.

## 주요 정정

- 출처·범위가 확인되지 않은 ‘약 180곳’, 전체 1,191건, 휘발성지방산 기여도 정밀 수치는 본문에서 제거했다.
- ‘새벽은 잰 적 없다’를 분석 대상 공개 정기 실측 표의 범위로 한정했다.
- 67.8%와 54.3%를 같은 크기로 비교하고 분모 1,761건을 표시했다.
- 처분은 기간 내 1사례로 표시했다. 사례와 개선명령·과태료 항목은 다르다.
- 최대값은 ‘희석배수 300’으로 표시했다. ‘기준을 300배 초과’와 구분한다.
- 2025년 표본 변경, 2026년 상반기 23건과 공통 시간대 비교를 설명했다.
- LLM은 문장 해석·도구 선택·설명, 단계는 규칙, 수치는 Python 계산임을 구분했다.
- ‘허위·중복 필터’를 반복 신고 집계 보정으로 정리했다. 허위 여부는 판단하지 않는다.
- 위치는 확인 2곳·추정 1곳·미확인 1곳으로 구분했다.
- 현장 전환에 저장·권한·동의·복구·위치·기상 검증이 필요함을 명시했다.
- API 실패 시 규칙 신고 해석·표·집계는 유지되지만 자연어 분석은 제한된다고 표시했다.
- 개인정보 설명은 별도 ID·연락처 필드와 자유문장 전송을 구분했다. 자유문장 마스킹은 아직 미구현이다.
- 15/15는 사전 정의한 15문항의 1회 평가임을 밝혔다. 임의 질문의 100% 정확도를 뜻하지 않는다.

## PDF 재생성

```powershell
pip install -r requirements-build.txt
python scripts/render_proposal_pdf.py
# 또는 PDF + 제출 ZIP
python scripts/make_submission.py
```

Windows의 맑은 고딕 글꼴을 사용한다. `requirements-build.txt`는 문서 제작 전용이며 Agent 실행 의존성과 분리되어 있다.

PDF는 기획서 HTML의 문구·카드·표를 읽어 벡터로 배치한다. 브라우저 미리보기와 PDF의 픽셀 단위 배치는 다를 수 있으므로 제출본 PDF를 기준으로 검수한다. 글자량이 크게 바뀌면 렌더러의 영역 검사와 실제 페이지 확인이 필요하다.
