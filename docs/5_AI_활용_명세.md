## 1. 서비스 안에서 쓰는 AI

| 항목 | 내용 |
|---|---|
| 모델 | **Claude Haiku 5.5** (Anthropic, 모델 ID `claude-haiku-5-5`) |
| 호출 방식 | Anthropic 공식 Python SDK(`anthropic`), Messages API |
| 바꾸는 법 | `.env` 의 `LLM_MODEL` (예: `claude-sonnet-5-5`, `claude-opus-5-5`) |
| 비용 | 질문 1건 약 1원(입력 약 6천·출력 약 5백 토큰), 신고 해석 1건 1원 미만 |

| 쓰는 곳 | AI가 하는 일 | AI가 하지 않는 일 | 코드 |
|---|---|---|---|
| 카톡 신고 해석 | 문장에서 마을·시각·강도(1~5)·냄새 종류·지명을 정해진 JSON 형식(구조화된 출력)으로 뽑음 | 단계 판단, 행동 결정 | `backend/tools/parse_report.py` |
| 말로 묻는 분석 | 질문 해석, 도구 5개 중 선택·조건 지정, 도구 결과를 기간·출처와 함께 설명 | 숫자 계산(도구가 함), 농장 지목 | `backend/agent/analyst.py` |

**프롬프트**: 두 곳 모두 코드 안의 `SYSTEM` 문자열에 그대로 있습니다(`parse_report.py`, `analyst.py`). 도구 정의(이름·설명·입력 형식)는 `analyst.py` 의 `TOOLS` 입니다.

**AI 없이 동작하는 부분**: 사건 묶기·단계 판단·행동(판단 엔진), 통계 계산, 문안(전화 대본·문자·농장 알림·민원서) 작성은 모두 규칙과 템플릿입니다. Claude가 막히면 신고 해석은 규칙 기반(`backend/fallback/rule_parser.py`)으로 바뀌고, 말로 묻는 분석만 꺼집니다.

**AI에 보내는 데이터**: 신고 문장 1개, 방문자 질문, 도구가 계산한 집계값. 신고자 정보·원본 행·사업장명·API 키는 보내지 않습니다.

## 2. 개발에 쓴 AI 도구

| 도구 | 활용 범위 |
|---|---|
| Claude Code (Anthropic, Claude Opus 5.5) | 코드 작성·수정(서버, 판단 엔진, 화면, 분석 Agent, 전처리 스크립트), 공공데이터 전처리(지오코딩·경계 받기), 화면 확인(브라우저 캡처), 자동 점검 스크립트, 기획서 HTML과 문서 초안 작성 |

팀이 직접 한 일: 문제 정의와 현장 조사(정보공개청구, 악취조사 DB 정리), 서비스 기획·판단 기준 결정, 원칙 결정(원인 농장 비표시, 풍향 비표시 등), 화면·기능 검토와 수정 지시, 최종 확인.
