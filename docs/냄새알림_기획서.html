07 판단 및 자율 수행 범위

판단은 Agent가, 되돌릴 수 없는 일은 사람이

Agent가 스스로

  • 신고 해석·되묻기
  • 사건 묶기·단계 판단
  • 지역·시간별 신고·처리 통계
  • 농장 주의 알림
  • 대표 민원 전화·문자(사전 등록 번호)
  • 통계·보고서 작성

사람 승인 후

  • 공식 민원 제출(마을 대표)
  • 판단 기준값 변경(담당자)
  • 농장 알림 대상 등록(농장 동의)

하지 않음

  • 특정 농장을 원인으로 단정
  • 원인 농장 추정·표시
  • 신고자 정보를 농장에 전달
  • 센터 원본 데이터 외부 LLM 전송
  • 같은 사건 반복 전화

08 Agent 개발 구성 · 모델 · Tool/API

LLM은 판단하고, 숫자는 도구가 계산한다

역할

주민·행정·농장 사이의 악취 대응 조정자

사용 모델

[LLM 모델명] 외부 API. 센터가 비용을 부담하므로 소형 모델 우선, 호출 횟수 최소화

원칙

LLM은 숫자를 만들지 않는다. 집계·추정은 도구가 하고, LLM은 해석과 문장을 맡는다
