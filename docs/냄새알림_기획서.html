07 판단 및 자율 수행 범위

판단은 Agent가, 되돌릴 수 없는 일은 사람이

Agent가 스스로

  • 신고 해석·되묻기
  • 사건 묶기·단계 판단
  • 지역·시간별 신고·처리 통계
  • 농장 주의 알림
  • 대표 민원 전화·문자(사전 등록 번호)
  • 통계·보고서 작성

사람 승인 후

  • 공식 민원 제출(마을 대표)
  • 판단 기준값 변경(담당자)
  • 농장 알림 대상 등록(농장 동의)

하지 않음

  • 특정 농장을 원인으로 단정
  • 원인 농장 추정·표시
  • 신고자 정보를 농장에 전달
  • 센터 원본 데이터 외부 LLM 전송
  • 같은 사건 반복 전화

원칙

LLM은 숫자를 만들지 않는다. 집계·추정은 도구가 하고, LLM은 해석과 문장을 맡는다

parse_report

hourly_daily

incident_list

measurement_stats

facility_stats

악취배출시설 읍면·리·구분별 집계

rank_sources

drafts

허브 목록은 2019년 기준, 중복 의심 항목 있음. 실측은 분기 1회, 단위 확인 중. 원인 농장은 추정·표시하지 않고, 신고·처리 사실만 보여 준다(명예훼손 방지)

개인정보

신고자는 익명 ID로만 구분. 농장에는 신고 수만 전달. Claude에는 신고 문장과 집계값만 보내고 신고자 정보는 보내지 않음

계산과 전송

숫자는 모두 PC 안의 도구가 계산하고 Claude는 설명만. 답마다 사용한 도구·조건·받은 데이터를 화면에 공개. 민원서의 실측 이력은 농장별이 아닌 구역 전체 통계로

재현성

가상 신고(시드 고정)·공개 데이터 동봉, 설치·사용자 매뉴얼, 새 폴더 설치 시험 완료. 신고 해석 결과는 원문과 함께 저장. Claude가 막히면 규칙 기반으로 계속 동작
