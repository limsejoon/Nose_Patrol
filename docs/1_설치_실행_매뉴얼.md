# 냄새알림 설치·실행 매뉴얼

대상: 제주빅데이터센터 담당자, 심사위원 (프로그래밍을 몰라도 그대로 따라 할 수 있게 썼습니다)
팀: 애월주민 · 「제주 AI·빅데이터 활용 AI Agent 개발 챌린지」 제출작

---

## 1. 준비물

| 항목 | 내용 |
|---|---|
| PC | Windows 11, 센터 PC 사양(i7-8700 / GTX 1060 / RAM 32GB)에서 동작. 그래픽카드는 쓰지 않습니다 |
| 브라우저 | Microsoft Edge (권장) 또는 Chrome. 화면은 1920×1080 기준 |
| 인터넷 | 처음 설치할 때 필요(패키지 내려받기). 실행 중에는 아래 3번의 주소만 씁니다 |
| 프로그램 | Python 3.12 이상 (3.14에서 검증) |
| 키(선택) | Claude API 키 — 말로 묻는 분석, 신고 문장 해석 / 브이월드 API 키 — 배경지도 |

키가 없어도 프로그램은 동작합니다. 키가 없으면 말로 묻는 분석만 꺼지고, 신고 해석은 규칙 기반으로, 배경지도는 OpenStreetMap으로 바뀝니다.

## 2. 설치 (처음 한 번)

### 2-1. Python 설치
1. https://www.python.org/downloads/windows/ 에서 **Python 3.12 이상** "Windows installer (64-bit)"를 내려받습니다.
2. 설치 첫 화면 아래의 **"Add python.exe to PATH"를 반드시 체크**하고 [Install Now]를 누릅니다.
3. 확인: 시작 메뉴에서 "명령 프롬프트"를 열고 `python --version` 을 입력해 `Python 3.12.x` 처럼 나오면 됩니다.

### 2-2. 프로그램 폴더 풀기
1. 제출 ZIP을 원하는 곳에 풉니다. 예: `C:\냄새알림`
2. 폴더 안에 `run.bat`, `README.md`, `backend`, `frontend`, `data`, `docs` 가 보이면 됩니다.

### 2-3. 키 넣기 (선택)
1. 폴더 안의 `.env.example` 을 복사해 이름을 `.env` 로 바꿉니다. (`run.bat` 을 처음 실행하면 자동으로 만들어 줍니다.)
2. `.env` 를 메모장으로 열고 아래 줄에 키를 붙여 넣은 뒤 저장합니다. 따옴표나 띄어쓰기 없이 씁니다.

```
ANTHROPIC_API_KEY=sk-ant-...        ← Claude API 키
VWORLD_API_KEY=...                  ← 브이월드 키 (없으면 비워 둠)
```

| 키 | 발급처 | 쓰는 곳 |
|---|---|---|
| Claude API 키 | https://platform.claude.com → API Keys (결제 카드 등록 필요) | 말로 묻는 분석, 카톡 신고 문장 해석. 모델 기본값: 분석 `claude-sonnet-5-5`(질문 1건 약 20원), 신고 해석 `claude-haiku-5-5`(1건 1원 미만) |
| 브이월드 API 키 | https://www.vworld.kr → 오픈API → 인증키 발급(무료). 서비스 URL `http://localhost:8000`, 활용 API: 지오코더·검색 | 배경지도(회색·지도·위성). 시설 좌표는 이미 계산해 동봉했으므로 키가 없어도 위치는 정확합니다 |

> 운영 시 키는 센터 담당자가 `.env` 에 넣어 두고, 이용자에게는 보이지 않습니다(화면과 브라우저로 키가 나가지 않음).

### 2-4. 실행
1. `run.bat` 을 **더블클릭**합니다.
2. 처음에는 패키지를 내려받느라 1~3분 걸립니다. 검은 창에 `서버 시작: http://127.0.0.1:8000` 이 나오면 준비가 끝난 것입니다.
3. Edge가 자동으로 열리며 센터 화면이 나옵니다. 열리지 않으면 브라우저 주소창에 `http://127.0.0.1:8000` 을 입력합니다.
4. 끝낼 때는 검은 창을 닫습니다.

두 번째부터는 `run.bat` 더블클릭만 하면 바로 열립니다.

## 3. 외부 접속 주소 (센터 허용 목록 등록 요청)

| 주소 | 용도 | 언제 |
|---|---|---|
| `api.anthropic.com` | Claude API (말로 묻는 분석, 신고 해석) | 실행 중 |
| `api.vworld.kr` | 브이월드 배경지도 타일 (서버가 대신 받아 PC에 저장) | 실행 중, 키가 있을 때 |
| `tile.openstreetmap.org` | 배경지도 (브이월드 키가 없을 때) | 실행 중 |
| `pypi.org`, `files.pythonhosted.org` | Python 패키지 설치 | 설치 때만 |

지도 라이브러리(Leaflet)와 데이터 파일은 모두 폴더 안에 들어 있어 다른 주소는 쓰지 않습니다.

## 5. 데이터 저장과 삭제 (센터 탑재 조건)

| 무엇 | 어디에 | 지우는 법 |
|---|---|---|
| 주민 신고·처리 기록(시연 포함) | **메모리에만** 있음. 파일로 저장하지 않음 | 화면 위 [↺ 초기화] 또는 프로그램 종료(검은 창 닫기) 시 모두 사라짐 |
| Agent에게 물은 질문·답 | 브라우저 화면에만 표시, 저장하지 않음 | 새로고침하면 사라짐 |
| 브이월드 지도 타일 | `data/processed/tiles/` | 폴더째 지워도 됨(다시 받음) |
| 이용자 개인 파일 | 사용하지 않음 | — |

이용자 퇴실 시 별도 삭제 작업 없이 [↺ 초기화] 또는 프로그램 종료로 모든 기록이 지워집니다.

## 6. 오류·제약사항

| 증상 | 원인과 해결 |
|---|---|
| `run.bat` 이 바로 닫힘 / "python을 찾을 수 없습니다" | Python 설치 때 "Add python.exe to PATH"를 체크하지 않음 → Python을 다시 설치하며 체크 |
| 패키지 설치가 멈춤 | 인터넷 또는 `pypi.org` 차단 → 허용 목록 확인 |
| 화면 위에 "규칙 기반(LLM 미설정)" | `.env` 에 Claude 키가 없음. 말로 묻는 분석만 꺼지고 나머지는 동작 |
| 말로 묻기에서 "Claude에 연결하지 못했습니다" | `api.anthropic.com` 차단(보안 프로그램) → 허용 목록 등록. 화면의 표·그래프는 그대로 사용 가능 |
| "Claude API 오류(401/429)" | 키가 틀렸거나 사용 한도 초과 → 키·한도 확인 |
| 배경지도가 회색 칸으로만 보임 | 지도 주소 차단 → `api.vworld.kr` 또는 `tile.openstreetmap.org` 허용. 시설·마을·경계 표시는 그대로 보임 |
| `Address already in use` / 8000 포트 사용 중 | 이미 실행 중인 창이 있음 → 기존 검은 창을 닫고 다시 실행 |

제약사항
- 대회판은 실제 전화·문자·민원 제출을 하지 않고 기록만 남깁니다.
- 카카오톡은 시뮬레이터 화면으로 대신합니다(현장판에서 카카오 채널 연결).
- 풍향은 기상청 API를 연결하지 않아 기본값(남풍 4m/s)을 씁니다. `.env` 의 `DEFAULT_WIND_FROM_DEG` 로 바꿀 수 있습니다.
- 마을 인구는 임시값입니다.

## 7. 평가용 Claude API 키 (심사위원용)

대회 규칙에 따라 평가용 키를 아래에 적어 제출합니다. 사용 한도가 걸려 있으며 평가 기간(2026.11.27) 종료 후 삭제합니다.

```
ANTHROPIC_API_KEY=(제출 직전에 기입)
```

이 키를 위 2-3의 방법으로 `.env` 에 넣고 `run.bat` 을 실행하면 됩니다.
